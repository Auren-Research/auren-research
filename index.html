001 — THE PROBLEM

Security research needs AI that reasons openly about exploits.

Researchers need models that can reason about malware, attack chains, and exploit analysis for authorized work. General-purpose models refuse or over-filter this exact content — even when the engagement is fully legitimate.

002 — THE SOLUTION

Security-specialized models, delivered where researchers already work.

Auren trains security-specialized language models on data from Argus, our proprietary pipeline — delivered as a subscription API built to plug into the agentic coding tools researchers already use daily.

004 — PROOF, PART ONE

Mixture-of-Collaboration beats matched MoE.

I designed and trained MoC — a sparse Transformer where routed experts collaborate through a learned mediator. In a matched 498.8M-parameter comparison on 9.83B tokens (single AMD MI300X), MoC beat an identical MoE baseline on validation perplexity: 20.70 → 20.40, with better expert load balance and zero dead experts.

Built on ~$200 of compute.
